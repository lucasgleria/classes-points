Eu preciso fazer um site bastante simples que ficará online, eu acessarei principalmente pelo celular. Esse site deve ser um MVP para meu controle durante minhas aulas de ingles de quantos pontos meus alunos tem.

O site deve ser simples, deve permitir que eu adicione nomes dos alunos e adicione os pontos que eles tem de forma simples e rápida, mantendo um histórico.

Maneiras de ganhar pontos: 
- Homework (Feita: +1 pts, Feita corretamente: +2pts)
- Games (A depender do jogo quantidade de pontos ganhos, portanto entre 1-100)
- Challenges (A depender do desafio, porntanto entre 1-100)
- Presence (Veio à aula: +1 pts)

Maneiras de perder pontos:
- Bad behavior (A depender do comportamento do aluno, portanto entre 1-100)

O workflow principal do software deve ser bastante simples, a tela inicial deve apresentar um dashboard com os pontos totais de todos em ordem de quantidade, deve haver um hamburguer lateral para clicar, o qual exibirá duas principais funções, uma função de adição que direcionará para outra tela, permitindo adicionar um novo aluno, ou selecionar um já existente para adicionar novos pontos a ele. Enquanto a outra função será especial para os alunos, eu não quero que eles vejam os pontos gerais de todos os alunos, portanto, cada um terá uma visualização individual do site onde eles poderão ver apenas a quantidade de pontos que eles tem em cada "modalidade" de pontos, e também quando perderem pontos, verão com uma "justificativa do professor" o motivo de ter perdido ponto. Para eles acessarem ssa visualização inicial, cada um deles receberá uma url diferenciada do site e eles terão seu login e senha, assim como eu como professor terei o login e senha da url principal, para que nenhum aluno tente acessar sem minha permissão.    

---

Utilize banco de dados sqlite server side para rodar o programa, utilize tecnologias leves e não se preocupe numa estrutura rigoroza de segurança, apenas preciso do sofware funcionando corretamente.
